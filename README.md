# Global Theme Switcher

## Description

This project is a React Vite application that uses the React Context API to manage a global Light Mode and Dark Mode theme.

## Features

- Uses createContext
- Uses custom ThemeProvider
- Uses useState to manage theme state
- Uses useContext to access global theme data
- Toggles between Light Mode and Dark Mode
- Applies dynamic CSS classes

## How to Run

```bash
npm install
npm run dev
